# 클라이밍장 랜덤 룰렛

## GitHub Pages 업로드 구조

- index.html
- assets/red-panda.png

`assets/red-panda.png` 위치에 원하는 렛서팬더 이미지를 넣으면 룰렛 중앙에 표시됩니다.
이미지가 없어도 기본 이모지로 대체되어 룰렛은 정상 작동합니다.

## 실행 방법

1. GitHub 저장소에 `index.html` 업로드
2. 저장소에 `assets` 폴더 생성
3. 최근에 만든 렛서팬더 이미지를 `red-panda.png`로 이름 변경 후 `assets` 폴더에 업로드
4. Settings > Pages에서 배포


현재 ZIP에는 요청한 렛서팬더 중앙 이미지가 포함되어 있습니다.
